# 0164 GitHub Epic checklist

## Why

An Epic shows at a glance what is done. So it may be one checklist, each item holding its Plan and pull request links, with no sub-issue links.

## Measurement

Epics that pass issue-check as a checklist
-
Epics

## Requirements

- 0164.1
    - Given Developer has an Epic checklist grouped by heading, with ticked and open items holding Plan URLs, some in `.github`
        - When issue-check judges it
            - Then it labels the Epic fitness-valid, and never asks GitHub for its sub-issues
