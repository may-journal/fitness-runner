### 2026.11.23.1451

> A check that reads a Vitest or Jest suite sees each test's groups, its tables and its cases.

- Feat: `lang.Test` gains `Groups`, the `describe` calls around a Vitest or Jest test.
- Feat: `lang.Test` gains `Table`, set for a test or group declared through `each` or `for`.
- Feat: `lang.Tests` gains `Grouped`, which the Node module sets.
- Feat: The Node module lists each requirement test's case rows with a fixed `name`, their `file:line` and step ID.
- Docs: Requirement 0004.8 states the group behavior and 0009.4 the case behavior, each a numbered acceptance.
